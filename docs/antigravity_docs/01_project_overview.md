# 프로젝트 전체 개요

## 프로젝트 구성

CarrotPilot 생태계는 **두 개의 핵심 레포지토리**로 구성됩니다.

| 레포지토리 | 역할 | 실행 환경 | 기술 스택 |
|-----------|------|----------|----------|
| **CarrotLink-dev** | 모바일 매니저 앱 | Android / iOS | Flutter (Dart) |
| **c3-v10-wip** | 자율주행 보조 소프트웨어 | comma 3/3X (AGNOS) | Python, C++, C |

---

## 시스템 연동 구조

```
┌──────────────────────┐         SSH / WebSocket / HTTP         ┌──────────────────────┐
│                      │ ──────────────────────────────────────▶ │                      │
│   CarrotLink-dev     │                                        │    c3-v10-wip        │
│   (모바일 앱)         │ ◀────────────────────────────────────── │    (comma 디바이스)    │
│                      │        실시간 데이터 / HUD 스트리밍        │                      │
├──────────────────────┤                                        ├──────────────────────┤
│ • SSH 원격 제어       │                                        │ • 차량 조향/가감속      │
│ • Git 브랜치 관리     │                                        │ • 딥러닝 경로 예측      │
│ • 파일 탐색/편집      │                                        │ • CAN/CANFD 통신      │
│ • 실시간 주행 화면    │                                        │ • 운전자 모니터링      │
│ • 설정 동기화        │                                        │ • 웹 HUD 서버         │
│ • Google Drive 백업  │                                        │ • 카메라/센서 처리     │
└──────────────────────┘                                        └──────────────────────┘
         │                                                                │
         ▼                                                                ▼
   사용자 스마트폰                                                    차량 OBD 포트
                                                                  (Panda 하드웨어)
```

## 통신 프로토콜

| 연동 방식 | 용도 |
|----------|------|
| **SSH** | 터미널 명령 실행, 파일 전송, Git 관리, 시스템 제어 |
| **WebSocket** | 실시간 HUD 데이터 스트리밍, 주행 정보 수신 |
| **HTTP/Flask** | CarrotPilot 웹 서버 API, 설정 조회/변경 |
| **Google API** | Google Drive 백업, Google Sign-In 인증 |

## 지원 차량

CarrotPilot은 현대/기아 차량을 주요 대상으로 하며, 하네스 연결 방식에 따라 구분됩니다:

- **CAN 통신 차량** — Comma 정품 Harness → Camera 연결
- **CANFD 일반 차량** — Comma 정품 Harness → Camera 연결
- **CANFD HDA2 (ADAS Module) 차량** — 사제 Harness → ADAS Module 연결

## 하드웨어 요구사항

- **comma 3 / 3X** — Qualcomm Snapdragon SoC 기반, AGNOS OS
- **Panda** — CAN 버스 인터페이스 하드웨어
- **차량용 하네스** — 차량 OBD 포트 연결용
