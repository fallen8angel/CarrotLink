# Carrot Settings Interaction Checklist (2026-03-09)

## 목표

- 리스트 행의 값 pill은 항상 실제 저장값을 기준으로 보인다.
- step(단위) 변경은 조작 단위만 바꾸고, 현재값 표시는 바꾸지 않는다.
- `- / +` 버튼은 시각 크기는 유지하면서 히트 영역만 조금 넓혀 오탭을 줄인다.
- 상위메뉴는 서버 원래 순서를 유지한다.
- 하위메뉴만 `abcd -> 가나다 -> 1234 -> 기타` 기준 자연 정렬을 적용한다.
- compact 이상 화면에서는 우측 조작부가 카드 폭에 따라 더 넓게 적응한다.
